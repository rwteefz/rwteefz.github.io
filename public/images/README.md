# images

Put pictures for your articles here.

On github.com: open this folder, click **Add file → Upload files**, drag your
image in, and press **Commit changes**.

Then use it in an article with:

    ![A short description of the picture](/images/your-file-name.jpg)

Keep file names lowercase with hyphens and no spaces, for example
`study-group-2026.jpg`. Resize large photos to about 1600 pixels wide before
uploading — the repository stays small and the page loads faster.
