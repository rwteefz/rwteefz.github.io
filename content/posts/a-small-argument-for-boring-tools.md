There is a particular kind of afternoon where you set out to write something and
instead spend four hours choosing the thing you will write it in. I have lost
many afternoons this way.

The cure, for me, was noticing which tools I still use a year later. They are all
boring.

## What boring buys you

A plain text file opens on every machine I will ever own. It survives the company
that made my editor going out of business. It diffs cleanly, so I can see what I
changed last Tuesday. It does not have a sync bug.

None of that is exciting. All of it compounds.

## The test I apply now

Before adopting a tool, I ask three questions:

1. If this project is abandoned tomorrow, do I still have my work in a usable form?
2. Can I explain the whole thing to someone in five minutes?
3. What happens when it breaks at the worst possible time?

Most software fails the first question badly. The data is in there somewhere, but
getting it out is a project of its own.

## Where this leaves me

A folder of Markdown files. Git for history. A browser to read the result.

It is not a system anyone would demo. It is a system that has not lost anything
in years, which turns out to matter far more.
